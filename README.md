<h1> Marketplace API </h1>
<span> created by Mostak Khan </span>

<h3>Problem Statement</h3>

<p>I created this web application with an intention of improving my programming and combining passion for coffee too, my take on was to create an ecommerce platform where roaster can sell their coffee for everyone, i took some inspiration from other marketplace platform.</p>

<h4> Main Objective </h4>
<ul>
<li> Sellers can list their products, manage inventory, payments </li>
<li> Buyers can browse, filter by origin/roast profile and purchase directly </li>
<li> The Platform handles transactions securely using a third party app using stripe (Not decided yet) </li>
</ul>

<h4>Technology Stack</h4>
<ul>
<li><b> Frontend: </b> Next.js (which is good for server-side rendering but in this case I will only be focussing on client-side rendering as I will use another for the server side, SEO, and great user experience) this can be found using this link <a href="https://github.com/mossstak/marketplace-frontend"> marketplace-frontend </a> </li>
<li><b> Backend: </b> ASP.NET Framework in C#, this has taught me a lot about OOP, Auth, DTOs, Rolebase and learning more about CRUD. This part of the project can be found in this repository </li>
<li><b>Database: </b> PostgreSQL (relational DB, ideal for e-commerce data) </li>
</ul>
